# DOTween

Activitat DOTween 
Prepareu un projecte amb DOTween per fer una build a Unity, a la qual es puguin veure dos 
escenaris des d’una mateixa càmera: - - - 
Un d’ells ha de tenir una representació a la qual un personatge (un cub), fa un 
DoJump cap a una posició elevada. 
L’altre ha de mostrar una seqüència que involucri com a mínim dos personatges (dos 
cubs), i facin alguna interacció concreta, com a mínim concatenant (append) o 
sincronitzant (Join), 5 accions diferents. 
Ha d’haver un botó per tal de reiniciar ambdues simulacions i un altre per fer play.
